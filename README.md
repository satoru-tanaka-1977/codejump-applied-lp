# BBB英会話スクール LP

CODEJUMP 応用編の「ランディングページ」課題として制作しているWebサイトです。

## 概要

HTML・CSS・jQueryを使用して、英会話スクールのランディングページを制作しています。

CODEJUMPの課題を通して、LPならではの構成や、スクロール連動のアニメーション演出について学習しています。

## 学習内容

- HTMLによるLP特有の構造設計（メインビジュアル・スライドイン・吹き出しなど）
- CSSアニメーション（`@keyframes`）によるメインビジュアルのフェード切り替え
- jQueryプラグイン（jquery.inview）によるスクロール連動のフェードイン・スライドインアニメーション
- ハンバーガーメニューの開閉処理の共通化（関数化）
- CSS疑似要素を使った吹き出し・ボタンの矢印・下線などの装飾
- 背景アニメーション（`background-position`の連続移動）
- レスポンシブ対応
- Git / GitHubによるバージョン管理

## 使用技術

- HTML5
- CSS3
- JavaScript（jQuery, jquery.inview）
- Git / GitHub
